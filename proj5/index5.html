  • a city skyline that looks like a circuit board
  • a circuit board shaped like a city skyline
  • a staircase that looks like a DNA helix

For each prompt, I experimented with four different values of num_inference_steps: 20, 60, 100, and 200, while fixing the random seed to 100.

Effect of varying the number of inference steps for different prompts.

I observed that there appears to be an optimal number of inference steps. As the number of steps increases, the images initially gain more fine-grained detail. For example, between 20 and 60 steps, the staircase that looks like a DNA helix becomes more structured, with clearer helix-like patterns appearing along the railings. However, when the number of steps is increased to 200, the image begins to overemphasize local details at the expense of global structure. In this case, the staircase loses its recognizable form and no longer clearly resembles either a staircase or a DNA helix. A similar trend appears in the city skyline that looks like a circuit board prompt. At lower step counts (around 20), the image preserves a strong city skyline structure while subtly incorporating circuit-like details. As the number of steps increases, the model increasingly prioritizes circuit features, eventually losing the visual identity of a city skyline. Overall, when generating images designed to resemble visual anagrams, increasing the number of inference steps improves detail up to a point. Beyond that point, the model tends to overblend features from both concepts, causing the image to lose a coherent primary structure.

Part 1: Sampling Loops

1.1 Implementing the Forward Process

In the forward diffusion process, we start with a clean image \( x_0 \) and gradually add Gaussian noise at each timestep. The parameter \( \bar{\alpha}_t \) represents how much of the original signal remains at timestep \( t \). As \( t \) increases, \( \bar{\alpha}_t \) decreases, and the image becomes increasingly noisy.

The forward process is defined as:

\[ q(x_t \mid x_0) = \mathcal{N}\left(x_t; \sqrt{\bar{\alpha}_t} x_0, (1 - \bar{\alpha}_t)\mathbf{I}\right) \]

Visualization of the forward diffusion process over time.

1.2 Classical Denoising

To establish a baseline, I attempted to denoise the noisy images using classical Gaussian blur filtering. This approach assumes that noise primarily consists of high-frequency components, which can be reduced by averaging nearby pixels.

I used a Gaussian kernel with size 5 and a standard deviation \( \sigma = 1.5 \). However, this method performed poorly: although some noise was reduced, much of the original image structure had already been destroyed by the diffusion process and could not be recovered.

Results of classical Gaussian blur denoising.

1.3 Implementing One-Step Denoising

In the next section, I implement a learned one-step denoising model that predicts the noise added at each timestep. We can remove this noise at each time step to try to recover our original image.

Forward process:

\[ x_t = \sqrt{\bar{\alpha}_t}\,x_0 + \sqrt{1 - \bar{\alpha}_t}\,\epsilon, \quad \epsilon \sim \mathcal{N}(0, I). \]

The UNet predicts the noise \( {\epsilon} \), so we can just solve for \( x_0 \) to remove the noise:

\[ \hat{x}_0 = \frac{x_t - \sqrt{1 - \bar{\alpha}_t}\,{\epsilon}} {\sqrt{\bar{\alpha}_t}}. \]

Results of One-Step Denoising

1.4 Iterative Denoising

Instead of removing noise one tiny step at a time (e.g., over 1000 diffusion steps), we can jump between timesteps using a formula that mixes the current noisy image with an estimate of the clean image in the correct proportions.

In this setup, the first index corresponds to the noisiest image, while the final index corresponds to the reconstructed clean image. Rather than denoising at every single timestep, we use strided timesteps and perform denoising only at those selected points.

Results of iterative denoising using strided timesteps.

Iterative denoising was the method that kept the most detail compared to the one-step estimate and Gaussian blur. It was able to preserve information about the sky and had more detailed outlines of the trees compared to the one-step estimate.

However, it does seem to hallucinate the top of the Campanile and adds a flat surface. This makes sense, since during this process there is no reinforcement of whether the model is choosing the correct prediction of the clean image. If this estimate deviates from the true clean image, the subsequent steps will continue to drift further from the original.

1.5 Diffusion Model Sampling

In the previous section, iterative denoising was used to recover a clean image from a noisy input. Here, we instead use the same iterative_denoise procedure to generate entirely new images.

Rather than starting from a clean image and adding noise, we begin directly from random Gaussian noise and set i_start = 0, corresponding to the noisiest timestep. As in the earlier experiments, this aligns with t=strided_timesteps[0] = 990.

Below are several images sampled from pure noise using the prompt "a high quality photo".

Images sampled from random noise using diffusion model sampling.

So why does this work? Sampling begins from random noise, but the diffusion model has learned how noisy images evolve toward the data distribution. At each denoising step, the model predicts a direction that moves the sample toward higher-probability regions of the learned image manifold. Repeatedly applying these guided denoising steps gradually removes noise and results in a coherent image, rather than a random trajectory.

1.6 Classifier-Free Guidance (CFG)

The images above were not the best, since some of them did not necessarily make sense. To improve the results, we use Classifier-Free Diffusion Guidance (CFG).

In CFG, we compute both a conditional noise estimate conditioned on the prompt and an unconditional noise estimate. The parameter \( \gamma \) controls the strength of the guidance:

\[ \epsilon = \epsilon_u + \gamma (\epsilon_c - \epsilon_u) \]

The difference between \( \epsilon_c \) and \( \epsilon_u \) is the guidance vector. Intuitively, this guides \( \epsilon_u \) toward \( \epsilon_c \). The parameter \( \gamma \) controls how strongly the unconditional estimate is influenced by the conditional one. This can be thought of as injecting prompt-specific signal.

Here, we use "a high quality photo" as the conditional prompt embedding and an empty string ("") as the unconditional prompt embedding.

Image generation results using classifier-free guidance.

1.7.2 Inpainting

Here, we only allow the diffusion model to change pixels inside a mask, while forcing all pixels outside the mask to stay exactly the same as the original image (with the appropriate amount of noise).

We can use the same procedure to implement inpainting, following the RePaint paper. We run the diffusion denoising loop, but at every step, after obtaining \( x_t \), we force \( x_t \) to match the original image \( x_{\text{orig}} \) wherever the mask \( \mathbf{m} \) is 0:

\[ x_t \leftarrow \mathbf{m} \odot x_t + (1 - \mathbf{m}) \odot \text{forward}(x_{\text{orig}}, t) \tag{A.5} \]

Here, we use the prompt "a high quality photo".

1.8 Visual Anagrams

Here, we create visual anagrams and optical illusions using diffusion models.

We denoise an image \( x_t \) at timestep \( t \) normally using prompt \( p_1 \), which gives a noise estimate \( \epsilon_1 \). At the same time, we flip \( x_t \) upside down and denoise it using a different prompt \( p_2 \), producing a second noise estimate \( \epsilon_2 \).

We then flip \( \epsilon_2 \) back, average the two noise estimates, and perform a reverse diffusion step using this averaged noise estimate.

The full algorithm is:

\[ \epsilon_1 = \text{CFG}(\text{UNet}(x_t, t, p_1)) \] \[ \epsilon_2 = \text{flip}\big(\text{CFG}(\text{UNet}(\text{flip}(x_t), t, p_2))\big) \] \[ \epsilon = \frac{\epsilon_1 + \epsilon_2}{2} \]

Here, UNet is the diffusion model from before, flip() is a function that flips the image, and \( p_1 \) and \( p_2 \) are two different text prompt embeddings. The final noise estimate used for denoising is \( \epsilon \).

Visual anagrams generated using flipped denoising.

1.9 Hybrid Images

Here, we implement factorized diffusion and create hybrid images, similar to what we did in Project 2.

To create hybrid images with a diffusion model, we use a similar idea to the visual anagrams above. We construct a composite noise estimate \( \epsilon \) by estimating noise using two different text prompts and then combining low-frequency components from one noise estimate with high-frequency components from the other.

The algorithm is:

\[ \epsilon_1 = \text{CFG}(\text{UNet}(x_t, t, p_1)) \] \[ \epsilon_2 = \text{CFG}(\text{UNet}(x_t, t, p_2)) \] \[ \epsilon = f_{\text{lowpass}}(\epsilon_1) + f_{\text{highpass}}(\epsilon_2) \]

Here, UNet is the diffusion model UNet, \( f_{\text{lowpass}} \) is a low-pass filter, \( f_{\text{highpass}} \) is a high-pass filter, and \( p_1 \) and \( p_2 \) are two different text prompt embeddings. The final noise estimate used for denoising is \( \epsilon \).

We generate hybrid images by combining low-frequency components of the CFG noise prediction from one prompt with high-frequency components from another, and then using this combined noise estimate in the diffusion denoising process.

Observations

When trying to generate images from pure noise, the model does not do a good job of producing clear, recognizable digits. However, the generated outputs often contain rounded or curved shapes, which resemble digits such as 0, 5, 6, 8, and 9. This happens because the model was trained only as a single-step denoiser and not as a full generative diffusion model. During training, it learns to map noisy images back toward the average structure of the training data, rather than learning how to iteratively refine pure noise into a realistic sample. As a result, when starting from pure Gaussian noise, the model tends to produce blurry, averaged features that reflect common patterns in the dataset. Since many MNIST digits contain curved strokes, these features dominate the outputs, while sharper, digit-specific details fail to emerge. In other words, the model is minimizing reconstruction loss by predicting a "mean-like" digit structure rather than sampling from the true data distribution. Without iterative denoising steps or a noise-conditioned objective, the model lacks the ability to generate diverse and well-formed digits from pure noise.

Part 2: Flow Matching

One-step denoising does not work well for generative tasks. Instead, we need to iteratively denoise images using flow matching. In this approach, we train a UNet to predict the flow from noisy data to clean data, allowing us to gradually transform noise into realistic images.

Intermediate noisy samples are generated using a linear interpolation between pure noise and clean images:

\[ x_t = (1 - t)x_0 + t x_1, \quad \text{where } x_0 \sim \mathcal{N}(0, I), \; t \in [0, 1]. \tag{B.3} \]

Flow can be interpreted as the velocity of this transformation, describing how the data moves through space over time:

\[ u(x_t, t) = \frac{d}{dt} x_t = x_1 - x_0. \tag{B.4} \]

2.4 Adding Class-Conditioning to the UNet

To improve sample quality and provide finer control over image generation, we extend the UNet to condition on the digit class (0 to 9). We represent the class-conditioning signal as a one-hot vector and inject it into the network using additional fully connected layers, alongside the time-conditioning signal.

To preserve the models ability to generate images without class information, we apply classifier-free dropout by randomly removing the class-conditioning signal 10% of the time during training. This allows the model to learn both conditional and unconditional behaviors and enables classifier-free guidance at sampling time, giving us explicit control over which digit is generated.
