Part 1.2: Finite Difference Operator

Let's compute the \(D_x\) and \(D_y\) derivatives with the "cameraman" image.
  • \( \frac{\partial \text{img}}{\partial x} \) computes the partial derivative with respect to x by convolving the image with the \(D_x\) filter. This convolution highlights the vertical edges in the image.
  • \( \frac{\partial \text{img}}{\partial y} \) computes the partial derivative with respect to y by convolving the image with the \(D_y\) filter. This convolution highlights the horizontal edges in the image.
  • The gradient points in the direction of the most rapid increase in intensity. The gradient magnitude image combines both horizontal (\(G_x\)) and vertical (\(G_y\)) intensity changes at each pixel: $$ ||\nabla \text{img}|| = \sqrt{\left(\frac{\partial \text{img}}{\partial x}\right)^2 + \left(\frac{\partial \text{img}}{\partial y}\right)^2} $$ As a result, the edge strength is represented by the gradient magnitude. Edges correspond to regions where the image intensity changes rapidly, so the gradient magnitude naturally highlights these areas.
  • The gradient magnitude image has varying intensities for gray pixels, capturing both weak and strong edges. To improve this, we can create an edge image by binarizing the gradient magnitude image so that each pixel is either 0 or 1, making edge detection simpler and more robust.
While we used threshold 0.1, we can try experimenting with different thresholds to see which one produces a better edge image.

Effect of Threshold Values on the Gradient Magnitude

There is a clear tradeoff between capturing all edges and suppressing noise. If the threshold is too low, the edge image includes noisy edges. Conversely, if the threshold is too high, important edges and image details may be lost.

Part 1.3: Derivative of Gaussian (DoG) Filter

A better approach would be to first smooth the image and then compute the gradient; this helps reduce noise while preserving meaningful edges, such as those visible in the grass region. We can smooth the image by applying a Gaussian filter and then repeat the previous steps to compute the x and y partial derivatives, the gradient magnitude, and the edge image on the smoothed image.

Partial Derivatives on the Smoothen Cameraman Image

What differences do you see?
  • After applying the Gaussian filter, the edges become more clearly defined, because Gaussian filter reduces noise while preserving the main structures in the image.
  • The noise, such as small edge responses in the grass region, is reduced while most of the important edges remain visible. For example, if you compare threshold 0.05 without Gaussian smoothing to threshold 0.05 with Gaussian smoothing, the latter retains stronger, clearer edges, while containing a less noisy edges.
  • Although the Gaussian kernel is not perfect—removing noise too aggressively may also weaken or eliminate some real edges—overall it produces a cleaner result: stronger edge signals are retained while unwanted noise is reduced.
We can combine these convolutions into a single step.
Before: Two separate convolutions
  1. Smooth the image with a Gaussian filter: I * G
  2. Compute derivatives using finite difference operators:
    (I * G) * Dx, (I * G) * Dy
This required two separate convolution steps for each derivative.
After: Single convolution per derivative
  1. Combine the Gaussian and derivative operators first:
    DoGx = G * Dx, DoGy = G * Dy
  2. Apply directly to the image:
    I * DoGx, I * DoGy
  3. Why it works: Convolution is associative:
    (I * G) * Dx = I * (G * Dx)
This reduces computation and achieves the same result with a single convolution per derivative.

Part 2.1: Image "Sharpening"

This section explores image sharpening by enhancing high-frequency details using unsharp masking.
  • Apply a Gaussian filter to extract the low-frequency components.
  • Subtract the blurred image from the original to isolate the high-frequency details.
  • Add these high frequencies back to enhance edges—this is the core of unsharp masking.
  • Demonstrate the effect on several images, including sharpening a deliberately blurred image.
  • Compare the original and sharpened images to assess the improvement in clarity and detail.

Evaluation: let's pick a sharp image, blur it and then try to sharpen it again. Here, k is the scaling factor that controls the strength of the sharpening. A higher k increases edge enhancement, while a lower k produces a subtler effect.
Isharpened = Ioriginal + k · (Ioriginal - Iblurred)

Sharpening Evaluation on SF photo

Observation: applying unsharp masking after Gaussian blur improves clarity, but the original image was not restored completely. The sharpened image is visually clearer than the blurred one, but some textures and exact pixel values are not identical. There could be several reasons for this:
  • Smoothing loses information: Gaussian blur averages pixel values, attenuating fine details and high-frequency components, which cannot be fully recovered.
  • Sharpening is approximate: Unsharp masking enhances the high frequencies it extracts, but cannot perfectly reconstruct the original image.
  • Practical limitations: Rounding, clipping, and frequency loss mean the sharpened image differs slightly from the original, even if the gaussian filter size and sigma are the same.

Part 2.2: Hybrid Images

The goal of this section is to create hybrid images following the approach described in the SIGGRAPH 2006 paper by Oliva, Torralba, and Schyns. Hybrid images are special static images that appear differently depending on how far away you view them.
The key idea is: high-frequency details dominate perception up close, while at a distance, only the low-frequency (smooth) components are visible. By blending the high-frequency part of one image with the low-frequency part of another, we can produce a single image that conveys different interpretations depending on viewing distance.
